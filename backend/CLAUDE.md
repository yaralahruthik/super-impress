## Project Overview

FastAPI backend for Super Impress, using Python 3.13, PostgreSQL, SQLAlchemy ORM, and JWT authentication.

## Development Setup

### Environment Management

This project uses **uv** (not pip) for dependency management - it's 10-100x faster and provides reproducible environments.

```bash
# Install dependencies and setup virtual environment
uv sync

# Activate virtual environment
source .venv/bin/activate

# Add/remove dependencies
uv add <package>
uv remove <package>
```

### Database Setup

PostgreSQL is required. Two modes available:

**Local Backend + Docker PostgreSQL (Recommended)**
```bash
# In .env, use: DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/super_impress

# From project root
docker compose up postgres -d

# From backend directory
uv sync
uv run fastapi dev
```

**Full Docker Mode**
```bash
# In .env, use: DATABASE_URL=postgresql+psycopg://postgres:postgres@postgres:5432/super_impress

# From project root
docker compose up -d
```

Key difference: hostname is `localhost` for local backend, `postgres` for Docker backend.

### Environment Variables

Copy `.env.example` to `.env` and configure:
- `DATABASE_URL`: PostgreSQL connection string (see modes above)
- `SECRET_KEY`: JWT secret (generate with `openssl rand -hex 32`)
- `ALGORITHM`: JWT algorithm (HS256)
- `ACCESS_TOKEN_EXPIRE_MINUTES`: Token expiry time

## Architecture

### Application Structure

```
app/
├── main.py              # FastAPI app initialization and router registration
├── config.py            # Global settings (DATABASE_URL) via pydantic-settings
├── database.py          # SQLAlchemy setup: Base, engine, SessionLocal, SessionDep
└── auth/                # Authentication module (feature-based organization)
    ├── config.py        # Auth-specific settings (JWT config)
    ├── models.py        # SQLAlchemy User model + Pydantic schemas
    ├── router.py        # API endpoints: /register, /login, /users/me, /change-password
    ├── service.py       # Business logic: password hashing, JWT creation, user CRUD
    └── validators.py    # Custom Pydantic validators (password complexity)
```

### Key Patterns

**Database Sessions**: Use `SessionDep` dependency for automatic session management
```python
from app.database import SessionDep

@router.get("/endpoint")
def endpoint(session: SessionDep):
    # session is automatically created and closed
```

**Authentication**: JWT-based with OAuth2PasswordBearer
- Token endpoint: `/login` (uses OAuth2PasswordRequestForm with username/password)
- Protected routes: Use `Depends(get_current_user)` from `app.auth.service`
- Password hashing: Uses pwdlib with Argon2 (via `PasswordHash.recommended()`)

**Configuration**: Pydantic settings auto-load from `.env`
- Global config: `app.config.Settings` (database)
- Auth config: `app.auth.config.AuthSettings` (JWT settings)

**Models & Schemas**:
- SQLAlchemy models use `Mapped` type hints (e.g., `Mapped[str]`)
- Pydantic schemas for validation: `UserCreate`, `UserPublic`, `Token`, etc.
- Password validation enforced via Pydantic `AfterValidator` (8-15 chars, complexity rules)

### Database Migrations

Alembic handles schema migrations:
- Migration files in `migrations/versions/`
- After modifying SQLAlchemy models in `app/*/models.py`, create migration with autogenerate
- Always review autogenerated migrations before applying

### API Routes

All routes prefixed with `/api`:
- `POST /api/register` - User registration
- `POST /api/login` - Login (returns JWT)
- `GET /api/users/me/` - Get current user (protected)
- `POST /api/change-password` - Change password (protected)
- `GET /api/test` - Health check

## Testing

- Test files use `test_*.py` naming convention
- Located alongside implementation files (e.g., `app/auth/test_password_validation.py`)
- Run with `uv run pytest`

## Dependencies

Key libraries:
- **FastAPI**: Web framework with automatic OpenAPI docs
- **SQLAlchemy 2.0+**: ORM with modern typed API
- **Alembic**: Database migrations
- **psycopg**: PostgreSQL adapter (binary version for performance)
- **pwdlib**: Password hashing with Argon2
- **PyJWT**: JWT token creation/validation
- **pydantic-settings**: Environment variable management
- **Ruff**: Linting and formatting

## Pre-commit Hooks

Install with `uv tool install pre-commit && pre-commit install`
- Runs automatically on commit
- Manual run: `pre-commit run` or `pre-commit run --all-files`
